
# Renters

A School of Cities web project examining housing affordability and rental market trends in Ontario.

Built with SvelteKit. To run locally:

```
npm install
npm run dev
```

## Pages

- **Rising Rents and Supply in Ontario's Cities** ([https://schoolofcities.github.io/renters/rising-rents-supply](https://schoolofcities.github.io/renters/rising-rents-supply)) - Exploring rental housing affordability over time, examining how rents have changed across Ontario cities, and a light exploration of supply. Data from CMHC Rental Market Survey.
